# Solar_Tracking_System_Using_Arduino
A single-axis Arduino-based solar tracking system using LDR light sensors and a servo motor to maximize solar panel efficiency.

# Arduino Single-Axis Solar Tracker
A simple, low-cost single-axis solar tracking system powered by an **Arduino Uno**. The system uses two Light Dependent Resistors (LDRs) to detect the position of the sun and a 180-degree servo motor to adjust the solar panel's orientation horizontally for optimal energy absorption.
### Components Used
- Arduino Uno
- 180-degree Servo Motor
- 2x LDRs (Light Dependent Resistors)
- 2x 10k Resistors (Pull-down)
- Solar Panel
- Breadboard & Jumper Wires
